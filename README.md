# Schedully - Class Schedule & Lock Screen Wallpaper Builder

Schedully is a sleek, modern Google Material 3 web application designed for students and professionals to build custom class timetables and generate high-resolution mobile/tablet lock screen wallpapers.

## Features

- 📅 **Interactive Timetable Generator**: Easily create, edit, and organize weekly class schedules.
- 📱 **Lock Screen Wallpaper Builder**: Turn your schedule into custom wallpapers formatted for smartphones and tablets.
- 🎨 **Material 3 Design**: Vibrant themes, dynamic dark mode support, and clean Google Sans typography.
- 📄 **Import & Export Options**:
  - Export to high-resolution PNG image or PDF.
  - Import / Export ICS calendar files and CSV data.
  - OCR Image parsing for auto-extracting schedule tables.

## Tech Stack

- **HTML5** & **Vanilla CSS** (Material Design 3 tokens & dynamic themes)
- **JavaScript (ES6+)**
- **Libraries**:
  - `html2canvas` for wallpaper image rendering
  - `jspdf` for document exports

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Enjoy building your timetable!
